## Oracle OS 0.1.0 + GENESIS 0.1.0

**Instalar (Android 8+):** descarregue `OracleOS.apk` e toque para instalar. Para o jogo, `GENESIS.apk`.

| Ficheiro | Para quê |
|---|---|
| `OracleOS.apk` | A app: guias incluídos, bússola, plantas, mapas, energia, emergência, aba Jogo |
| `GENESIS.apk` | O jogo (fazenda, bichinho, linhagem) — abre pela aba JOGO |
| [`Qwen3.5-0.8B-Q4_K_M.gguf`](https://huggingface.co/unsloth/Qwen3.5-0.8B-GGUF/resolve/main/Qwen3.5-0.8B-Q4_K_M.gguf) | IA local (opcional, 508 MB, no Hugging Face — mesmo SHA-256): Sistema → Importar GGUF |
| `Oracle-Impressao-PT.pdf` / `Oracle-Print-EN.pdf` | Todos os guias para imprimir em A4 |
| `SHA256SUMS.txt` | Somas para conferir os ficheiros |

Novidades: introdução animada em 3D low-poly, poupança extrema de energia, pacote de impressão, acervo em árvore, 71 guias PT/EN (inclui parto, sementes, animais, ofícios, química básica, construção natural, comunicação sem energia, calendário, comunidade), e o jogo GENESIS.

APKs assinados com chave de desenvolvimento (versão inicial). Funciona sem internet depois de instalado.
